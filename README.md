# 答题卡题项分析

针对“卷式漏扫、部分题码残留”的答题卡做按标准题统计：网页上传卷式对照 CSV 与答题 CSV，
系统自动判定每张卡与哪些卷式相容，再按标准题统计各选项人数、漏答人数与待核题格。

## 快速启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

数据保存在名为 `exam_data` 的卷中（容器内 `/app/data/app.db`），重建容器不会丢失。

本地开发：

```bash
python3 -m pip install -r requirements.txt
EXAM_DB=./data/app.db python3 wsgi.py     # http://localhost:8000
```

测试：

```bash
python3 -m pip install pytest
python3 -m pytest -q
```

示例文件在 `samples/`：先导入 `answers.csv`，再提交 `form_A.csv`（名称为“A卷”），
可看到 `C004` 单独列出、`C002` 第 2 题计漏答；再提交 `form_B.csv`（名称“B卷”）观察重判。

## 数据格式

**卷式对照 CSV**（`题号, 选项字母, 标准题码, 标准选项`）

| 题号 | 选项字母 | 标准题码 | 标准选项 |
|------|----------|----------|----------|
| 1    | A        | Q01      | A        |
| 1    | B        | Q01      | B        |

- 每行把一个“印刷题号 + 印刷选项字母”映射为标准题码与标准选项。
- 同一卷式内，每个标准题码只能出现一次（唯一对应一个印刷题号），每个标准选项也不能重复。
- 支持 UTF-8 / GBK；表头可用中文或英文别名，无表头时按上述列序解析。

**答题 CSV**（`卡号, 题号, 涂选字母, 实扫题码`），每卡每道单选题一行：

| 卡号 | 题号 | 涂选字母 | 实扫题码 |
|------|------|----------|----------|
| C001 | 1    | A        | Q01      |
| C002 | 2    |          |          |

- “涂选字母”“实扫题码”可以为空（漏扫）。
- 导入答题 CSV 会整体替换现有答题数据并重算。

## 判定规则

**相容卷式**：该卷式的题号集合与整卡题号完全一致，并且卡上每个非空实扫题码等于该卷式的标准题码、
每个非空涂选字母是该卷式在对应题号下的合法字母。

对每张卡、每道标准题：

| 情况 | 处理 |
|------|------|
| 卡无任何相容卷式 | 不参与任何题统计，在“无可相容卷式的卡”中单列 |
| 所有相容卷式都印了该题，且归一后作答一致 | 计入对应选项；空答计为漏答 |
| 相容卷式之间归一作答不一致，或只有部分相容卷式印了该题 | 该题标记“待核”，不计入选项与漏答 |
| 所有相容卷式都未印该题 | 跳过 |

“归一作答”指把各卷式的字母按卷式映射换到标准选项后比较，因此不同卷式同义映射不会误判分歧。

**人工核对**：统计页的“待核题格”可给出结论——计漏答 / 跳过不计 / 判为某选项。结论保存后重算并覆盖自动判定。
若之后的卷式补交或题码订正使该题格重新一致，则以重算结果为准（过时结论自动失效）。

## 增量维护与一致性

- **补交卷式**：同名卷式整份替换；提交后自动重判全部卡，原先“无可相容卷式”的卡可能因此计入。
- **订正题码**：指定卷式、印刷题号和新标准题号（可同时改标准选项），立即重判；旧统计中失效的计数被撤下。
- **重算期间**：旧统计快照保持为当前生效统计，页面顶部显示“重算中”，完成后自动刷新；历史快照仍可只读查看。
- **原子生效**：每次变更的“卷式/题码/核对结论 + 新统计 + 生效指针”在同一个 SQLite 事务内提交。
  任一步失败则整体回滚，原状态保持不变，页面明确提示失败原因。
- 旧快照保留最近 6 个（`engine.prune_runs`），可用于对比。

## 大数据量与内存

库里有数万张卡时，重算与页面读取都不再把整库读进内存：

- 重算按卡号分批（`engine.CARD_BATCH_SIZE`，默认 500 张/批）流式扫描 `answer_rows`，
  每批评完立即写入快照表；内存只与“每批卡数 × 每卡题数”有关，**不随卡数增长**。
  人工作答结论也按批加载，同样与累计数量无关。
- 答题 CSV 导入同样逐行解析、分批写库，不再缓冲整份行列表。
- 统计页只读取题级汇总；待核题格与卡号明细分页展示（每页 200 条），导出 CSV 只读汇总表。
- 卷式与每卡题数不变时，30 000 张 × 20 题的重算峰值约 14 MiB；60 000 张仍是同一量级，
  可在 256 MiB 地址空间限制内完成（`docker compose` 默认即满足）。
- 卷式、题码、核对结论与新统计在同一事务内切换，所以同一版的页面汇总、CSV 导出与
  按卡号查询的明细始终一致；重算进行中页面仍展示上一版完整结果，可正常导出。

## 主要接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 总览、导入、卷式列表、订正入口 |
| GET | `/runs/<id>` | 某次统计快照（待核题格可提交人工结论；`flagged_offset` 分页） |
| GET | `/cards` | 无相容卷式的卡、按卡结果（`cards_offset` 分页） |
| GET | `/export/<id>.csv` | 导出统计 |
| GET | `/api/status` | 重算状态 / 当前快照 / 状态版本 |
| POST | `/answers` | 导入答题 CSV |
| POST | `/forms` | 补交或替换卷式 |
| POST | `/forms/correct` | 订正题码（`form_id, q_no, new_code[, new_option]`） |
| POST | `/review` | 人工核对结论（`card_no, std_code, resolution`） |

## 结构

```
examapp/
  app.py       Flask 路由、后台任务队列、事务边界、分页读取
  engine.py    CSV 流式解析校验、相容判定、分批统计与快照写入
  db.py        SQLite 连接与表结构
  templates/   页面
tests/         引擎与端到端测试（pytest）
samples/       示例 CSV
```
